# 学习与成长记录 V2 / 学習・成長記録

静态个人学习记录网页。**本分支为验收版，main 仍为原网站。**

## 页面

- 今日：每日任务、完成情况、小红书分享
- 计划：默认晨间安排、当日任务、白天主线计划
- 主线：Java / SQL / 日本語等长期学习目标、每日任务、笔记、代码片段、AI 规划 JSON 导入
- 日记：晨间日记、学习感想、今日总结
- 统计：原有任务记录以及主线实际学习时间

顶部可切换记录日期及中文 / 日文界面。

## 临时预览与本地试用

临时预览（第三方静态文件代理，供验收用）：
https://raw.githack.com/Simin1012/my-study-journal/v2-development/index.html

如预览代理不可用，可下载本分支 ZIP，解压后在 Chrome 中打开 `index.html`。页面只使用静态 HTML、CSS 和 JavaScript，无须服务器。

**请仅用虚拟测试记录验收。** 浏览器的本地存储按网站来源隔离；临时预览、本地文件及正式 GitHub Pages 之间不会自动共享记录。不要把公司机密代码放在公共代码仓库或第三方预览网址中。

## 备份及兼容性

- 原版数据保留在 `momo-study-journal-v1` 等旧存储键中。
- 新版主线存储为 `momo-study-mainlines-v2`。
- 「完整备份V2」导出旧记录与主线记录；「恢复完整备份」会覆盖所包含的数据，请先备份。
- 未填写实际学习分钟数与明确填写 0 分钟是不同状态。
- 小红书分享正文在独立编辑区编辑，自动读取日记及任务；重新生成正文需要确认。

## 开发及测试

CI: `.github/workflows/v2-smoke.yml`，使用 Chromium/Playwright 测试导航、任务保存、日记与分享、语言、AI 导入、日期切换、备份恢复及移动端。

通过用户实际验收后，再合并 `v2-development` 到 `main` 发布 GitHub Pages。
